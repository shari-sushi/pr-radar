基本設定

保存には保存ボタンを押す

  1. github.com/settings/personal-access-tokens/new を開く（Fine-grained token）
  2. Resource owner — 対象リポジトリを持つ organization（個人リポジトリなら自分）
  3. Expiration — 短めに。90日など
  4. Repository access — Only select repositories → 対象の3つだけ
  5. Repository permissions — Pull requests を Read-only。これだけ
  6. Generate token → 出てきた値をこの欄に貼る

Metadata: Read-only は自動で付く（外せない）。Contents は付けないこと —— 付けるとリポジトリを丸ごと落とせるトークンになる。

org の設定によっては、発行後にオーナーの承認待ちになる。SAML SSO が必須なら Configure SSO で認可する。

classic token（github.com/settings/tokens）は repo スコープに書き込み権限まで含むので使わない。

自分以外で追う人の GitHub ID。複数はカンマか改行で区切る。ここに載せていない人の PR は「ほかの人のPR」に回る。打った時点で盤面に反映されるが、残すには「保存して更新」を押す。
owner/repo を1行ずつ。打った時点で盤面に反映されるが、残すには「保存して更新」を押す。
変更はありません 設定はこのブラウザに保存されます（トークンは key.js の鍵で暗号化）。読み取り専用のトークンを使ってください。
