設定

GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens で発行。Resource owner を example-org、Repository access を対象の3つ、権限は Pull requests: Read-only だけ。org の設定によっては承認待ちになる。classic token の repo は書き込み権限も含むので使わない。
自分以外で追う人の GitHub ID。複数ならカンマ区切り。チェックを入れた人の PR が「自分たちのPR」に出る。外した人の PR は盤面から消える（自分にレビュー依頼が来ているものだけは残る）。ここに載せていない人の PR は「ほかの人のPR」に回る。切り替えた時点で盤面に反映される（次に開いたときも残すには保存）。
owner/repo を1行ずつ。下のトグルはヘッダーのものと同じ絞り込みで、押した時点で盤面に反映される（次に開いたときも残すには保存）。
盤面に出すレーン。外したものは丸ごと消える。切り替えた時点で反映される（次に開いたときも残すには保存）。
秒。60*30 のように四則演算でも書ける。0 か空で自動更新を止める。
〜
この時間帯は自動更新しない。更新ボタンと r はいつでも効く。19:00 〜 09:00 のように日をまたぐ指定もできる。空にすると止めない。
メモのボタンにホバーしてから吹き出しが出るまで。1秒までは0.1秒刻み、そこから5秒までは0.5秒刻み。0 で待たずに出る。動かした時点で保存される。
設定はこのブラウザに保存されます（トークンは key.js の鍵で暗号化）。読み取り専用のトークンを使ってください。
